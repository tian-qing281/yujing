# 部署文档

> 最后更新 2026-05-18 · 单机部署 + 开发环境 / 生产建议

## 1. 系统要求

| 资源 | 最低 | 推荐 |
|------|------|------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 20 GB | 50 GB SSD |
| OS | Windows 10/11、Linux | Linux Ubuntu 22.04 |
| Python | 3.10 | 3.10 / 3.11 |
| Node | 18 | 20 LTS |
| GPU | 可选 | 4G+ 显存（BERT 加速）|

## 2. 必备外部服务

| 服务 | 必备性 | 说明 |
|------|-------|------|
| **DeepSeek API key** | 必填 | Agent / ABSA / 全文摘要依赖 |
| **MeiliSearch** | 可选 | 缺省走 SQLite ILIKE 兜底 |
| **HuggingFace 国内镜像** | 可选 | 国内访问设 `EMBED_USE_MIRROR=1` |
| OpenAI API key | 可选 | 可与 DeepSeek 二选一 |
| Jina Reader | 可选 | 文章正文抓取免费 API，无需 key |

## 3. 环境变量（.env）

```bash
# === 必填 ===
DEEPSEEK_API_KEY=sk-xxxxx

# === 可选 ===
DATABASE_PATH=runtime/db/yujing.db
LLM_PROVIDER=deepseek                # 或 openai
OPENAI_API_KEY=sk-xxxxx

# 向量化
SEMANTIC_CLUSTER=1                   # 启用 BGE 聚类
EMBED_USE_MIRROR=1                   # 国内镜像 hf-mirror.com
EMBED_DIM=512

# 聚类阈值
SEMANTIC_CLUSTER_THRESHOLD=0.62
INCR_CLUSTER_THRESHOLD=0.69
SEMANTIC_TIME_HALF_LIFE_HOURS=12

# MeiliSearch
MEILI_HOST=http://localhost:7700
MEILI_MASTER_KEY=yujing-dev-key
MEILI_BINARY_PATH=./runtime/meili/meilisearch.exe   # Windows

# 早报
BRIEF_HOUR=8
BRIEF_MINUTE=0

# CORS
CORS_ALLOW_ORIGINS=http://localhost:5173

# 爬虫 Cookie（按需）
WEIBO_HOT_SEARCH_COOKIE=./cookies/weibo.txt
ZHIHU_HOT_QUESTION_COOKIE=./cookies/zhihu.txt
```

## 4. 后端启动

```powershell
# 1. 克隆
git clone <repo> yujing
cd yujing

# 2. 虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1     # Windows
# source .venv/bin/activate      # Linux

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置
copy .env.example .env
# 编辑 .env 填 DEEPSEEK_API_KEY

# 5. 初始化数据库（首次启动自动创建表）
# 无需手动建表

# 6. 启动
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

启动后访问 `http://127.0.0.1:8000/docs` 查看 OpenAPI 接口文档。

## 5. 前端启动

```powershell
cd yujing-ui
npm install
npm run dev
# 浏览器打开 http://localhost:5173
```

生产构建：

```powershell
cd yujing-ui
npm run build
# 产物在 yujing-ui/dist/
```

## 6. MeiliSearch（可选）

Windows：下载 [meilisearch.exe](https://github.com/meilisearch/meilisearch/releases) 放到 `runtime/meili/`，后端启动会自动拉起。

Linux：
```bash
curl -L https://install.meilisearch.com | sh
mv meilisearch /usr/local/bin/
```

或 Docker：
```bash
docker run -d -p 7700:7700 \
  -e MEILI_MASTER_KEY=yujing-dev-key \
  -v meili_data:/meili_data \
  getmeili/meilisearch:latest
```

## 7. 模型预下载

首次启动会从 HuggingFace 下载：
- `BAAI/bge-small-zh-v1.5`（≈ 100MB）
- `Johnson8187/Chinese-Emotion`（≈ 400MB）

国内网络慢，建议先用 `huggingface-cli` 离线下载到 `~/.cache/huggingface/`，或设 `EMBED_USE_MIRROR=1` 走 hf-mirror。

## 8. Cookie 准备

部分爬虫源需 Cookie（无 Cookie 则降级返回空）：

| 源 | 获取 | 必备性 |
|----|------|------|
| 微博 | 浏览器登录后导出 cookie 字符串 | 推荐 |
| 知乎 | 同上 | 必须（反爬严）|
| 头条 | 同上 | 推荐 |
| 百度热搜 | 同上 | 推荐 |
| B站 / 澎湃 / 华尔街 / 财联社 | 无需 | - |

操作：把 cookie 文本存到 `cookies/{source_id}.txt`，或调 `POST /api/cookies/save` 接口。

## 9. 数据初始化（首次部署）

```powershell
# 1. 触发一次同步把数据拉进来
curl http://127.0.0.1:8000/api/sync

# 2. 等 30s 让爬虫跑完，再触发聚类
curl -X POST "http://127.0.0.1:8000/admin/events/rebuild?semantic=1&lookback_hours=72"

# 3. 重建语义索引
curl -X POST "http://127.0.0.1:8000/admin/semantic/index?lookback_hours=72"
```

## 10. 后台任务（自动）

启动后 APScheduler 接管以下定时任务：

| 任务 | 周期 |
|------|------|
| 爬虫同步 | 5 min |
| 增量聚类 | 30 min |
| Centroid 校准 | 2 h |
| 早报生成 | 每天 BRIEF_HOUR:BRIEF_MINUTE |

无需人工干预。日志写到 `runtime/logs/`。

## 11. 生产部署（建议）

### 11.1 Linux + systemd

```ini
# /etc/systemd/system/yujing.service
[Unit]
Description=Yujing Backend
After=network.target

[Service]
WorkingDirectory=/opt/yujing
ExecStart=/opt/yujing/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always
EnvironmentFile=/opt/yujing/.env

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable yujing
systemctl start yujing
```

### 11.2 Nginx 反向代理

```nginx
server {
    listen 80;
    server_name yujing.example.com;

    location / {
        root /opt/yujing/yujing-ui/dist;
        try_files $uri /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_buffering off;          # SSE 必须关
        proxy_read_timeout 300s;
        proxy_http_version 1.1;
    }
}
```

### 11.3 反爬代理（按需）

爬虫量上来后建议配代理池：在 `app/crawler/base.py` 的 httpx Client 注入 `proxies={"http://": "http://proxy:8080"}`。

## 14. 常见问题

**Q：模型下载失败？**
A：设 `EMBED_USE_MIRROR=1` 走 hf-mirror，或用 `huggingface-cli download` 提前下载。

**Q：BERT 占内存过高？**
A：把 `EMBED_BATCH=8` 调低，或不启用 BERT 走规则路径（不设 `BERT_AVAILABLE` 即可）。

**Q：MeiliSearch 启动失败？**
A：检查 `runtime/meili/` 下是否有 `meilisearch.exe`；端口 7700 是否冲突。可不启用，会自动降级 ILIKE。

**Q：Agent 没响应？**
A：检查 DEEPSEEK_API_KEY 是否有效；查 `runtime/logs/agent/` 日志看具体报错。

**Q：爬虫返回 403？**
A：源方反爬；检查对应 Cookie 是否失效，调 `POST /api/cookies/save` 更新。
