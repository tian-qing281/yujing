# 舆镜 vs 鱼皮 AI 热点监控工具 · 差异分析

> 对标项目：[liyupi/yupi-hot-monitor](https://github.com/liyupi/yupi-hot-monitor)（Stars 446 · Forks 97 · Express 5 + React 19 + OpenRouter + Socket.io · 2026 年编程导航 AI 编程实战教学项目）
>
> 对比时间：2026-05-15

---

## 一、定位差异（最核心）

| 维度 | 鱼皮 yupi-hot-monitor | 舆镜 yujing |
|---|---|---|
| **产品定位** | 个人监控工具（"让 AI 帮你盯热点"） | 企业级舆情态势平台（多平台、多维度、可解释） |
| **核心动作** | 关键词监控 → 命中推送 | 全网持续抓取 → 事件聚合 → 多维分析 → 可解释决策 |
| **典型用户** | AI 博主 / 内容创作者 | 政企舆情分析师 / 决策辅助 |
| **数据生命周期** | 推送即焚（关注命中事件） | 沉淀建库（事件谱系 + 时序回溯 + Agent 检索） |
| **学习/教学属性** | 强（视频 + 文字 + 简历 + 面试一条龙） | 无（参赛实用工具 + 学术原型） |

**一句话区分**：鱼皮做的是"AI 命中推送器"（push 模型），舆镜做的是"舆情数据库 + 可解释分析中台"（pull + 持续沉淀模型）。

---

## 二、功能矩阵对比

### 2.1 数据采集

| 能力 | 鱼皮 | 舆镜 |
|---|---|---|
| 数据源数量 | 8+（Twitter / Bing / HackerNews / 搜狗 / B 站等） | 8（微博 / 百度 / 头条 / B 站 / 知乎 / 澎湃 / 华尔街见闻 / 财联社） |
| 数据源风格 | 海外为主（Twitter / Bing / HN） | 国内为主（更贴合中文舆情场景） |
| 抓取触发 | 关键词驱动按需检索 | 定时全量榜单 + 关键词全网搜索两种模式 |
| 内容深度 | 标题 + 摘要（聚合用） | 标题 + 摘要 + 正文（`extract_article_content`） + 弹幕 + 评论（B 站） |
| 抓取技术 | Axios + Cheerio | aiohttp + Playwright（按源选） + B 站 WBI 签名 |
| 凭据管理 | OpenRouter Key 一把梭 | 多源独立 cookie（B 站 / 微博等）+ 凭据资产配置 UI |

**舆镜独有**：B 站弹幕 + 评论二级抓取、凭据资产管理面板（CredentialModal · 公开源 / 私有源分流）。

### 2.2 AI 智能层

| 能力 | 鱼皮 | 舆镜 |
|---|---|---|
| LLM 接入 | OpenRouter 单接口 | 多模型路由（DeepSeek / Qwen / 本地）+ 任务类型适配 |
| AI 查询扩展（同义改写召回率） | ✅ 核心卖点 | ✅ AI 助手内置 + Agent ToolCall 链路 |
| AI 真假识别 / 相关性 | ✅ 关键词命中后过滤 | ✅ 事件聚合阶段 LLM 去重判定 |
| AI 摘要 | ✅ 单条摘要 | ✅ 单条摘要 + 事件级聚合摘要 + 雷达图维度抽取 |
| ABSA（多维情感） | ❌ | ✅ F6 维度雷达（情绪 / 客观 / 强度 / 覆盖 / 极性 / 时延）|
| 用户画像（embedding 召回） | ❌ | ✅ V2 BGE article embedding + view_history 加权 centroid → 邻近召回 Top12 真实关键词 tag |
| 影响指数算法 | ❌（仅按热度排序） | ✅ per-source 差异化（baseScore + 平台 bonus），`explainImpact()` 4 行人话拆解 |
| Agent 多轮记忆 | ❌（一次问一次答） | F3 路线图（待交付） |

**舆镜独有**：embedding 邻近召回 + ABSA 维度雷达 + 可解释影响指数。

### 2.3 推送 / 实时性

## 三、技术栈对比

| 层 | 鱼皮 | 舆镜 |
|---|---|---|
| 前端 | React 19 + Vite + Aceternity UI（炫酷动效） | Vue 3 + Vite + 自研 editorial 风格（华尔街日报基调）+ ECharts |
| 后端 | Express 5 + Node.js + Socket.io | FastAPI + uvicorn + Python asyncio |
| 数据库 | Prisma + SQLite | SQLAlchemy + SQLite + ChromaDB（embedding） |
| 抓取 | Axios + Cheerio | aiohttp + Playwright + B 站 WBI |
| AI | OpenRouter（统一网关） | DeepSeek + Qwen + BGE embedding（多模型路由） |
| 任务调度 | node-cron | APScheduler |
| 实时通信 | Socket.io | 暂无 |

**技术栈倾向**：
- 鱼皮选 Node 全栈是为了"教学一致性"（前后端同语言降低学习门槛）+ AI Vibe Coding 流畅度
- 舆镜选 Python 后端是因为 NLP / embedding / 数据分析生态在 Python 侧远优于 Node

## 四、差异化优势总结

### 4.1 舆镜领先项（适合答辩主打）

1. **可解释影响指数**：F7 `explainImpact()` 输出 `平台·排名 / 基础分 / 平台热度加权 / 合计` 4 行拆解，鱼皮无此类透明度设计
2. **embedding 用户画像**：V2 BGE 邻近召回真实关键词 tag，鱼皮停留在"关键词命中"层
3. **ABSA 维度雷达**：F6 多维情感，鱼皮无情感分析
4. **事件聚合 + 时序回溯**：5578 事件谱系，鱼皮是单条原子推送
5. **多源凭据资产管理**：CredentialModal 公开/私有源分流，鱼皮仅一把 OpenRouter Key
6. **报告导出**：PDF 已落地（python-docx + python-pptx 路线图），鱼皮无导出能力
7. **editorial 视觉体系**：华尔街日报风格，token 化设计系统（accent-coral + neutral-warm 体系），鱼皮走 Aceternity UI 炫酷路线（两种审美无优劣，但舆镜更贴合"严肃舆情"语境）

### 4.2 舆镜需补齐项（鱼皮领先）

1. **WebSocket 实时推送**：F2 待交付（30s 内触达是鱼皮强卖点）
2. **Agent Skills 生态**：鱼皮已封装 Cursor/VSCode Copilot/Claude Code 三端通用包
3. **MCP 协议接入**：可作为 V3 路线图考虑
4. **海外数据源**：Twitter / HackerNews / Bing 缺失（如答辩需要"全球视角"可补一个 RSS 聚合源）

### 4.3 双方共同优势项（无差异）

- AI 查询扩展 / 真假识别 / 摘要：基础功能两边都有
- 8+ 数据源聚合：数量级相当
- SQLite 轻量部署：上手友好

## 五、答辩话术建议

> 当被问"你这个跟鱼皮那个有什么区别"时：

**短回答**（30 秒）：
> 鱼皮的项目是面向 AI 博主的个人监控推送工具，核心是"实时命中即推"；舆镜是面向舆情分析师的企业级中台，核心是"全网持续沉淀 + 多维可解释分析"。我们的影响指数有 4 行人话拆解，画像基于 BGE embedding 邻近召回，事件谱系有 5578 个聚合，是完全不同定位的产品。

**长回答**（2 分钟）：
> 1. 定位：鱼皮是 push 模型（盯关键词→推送），舆镜是 pull + 沉淀模型（全网抓取→建库→分析）
> 2. AI 深度：鱼皮做"命中后过滤"，我们做"全链路可解释"——影响指数 4 行拆解、ABSA 多维雷达、embedding 用户画像
> 3. 数据资产：鱼皮单条原子推送，我们 5578 事件谱系 + 时序回溯 + PDF 报告导出
> 4. 视觉语言：鱼皮走 Aceternity UI 炫酷路线，我们走华尔街日报 editorial 严肃路线，更贴合舆情场景
> 5. 短板诚实交代：实时推送和 Agent Skills 生态我们暂未做，列在了 F2 / V3 路线图里

## 六、结论

两个项目**不是同一赛道竞品**：

- **鱼皮** = AI Vibe Coding 教学项目 + 个人推送工具（教学价值 > 工业价值）
- **舆镜** = 参赛+实用项目，企业级舆情分析中台（工业价值 > 教学价值）

舆镜的差异化护城河在 **可解释 AI**（F7 explainImpact）+ **数据沉淀深度**（事件谱系 + embedding 召回）+ **领域适配**（中文舆情 + editorial 视觉）。鱼皮的护城河在 **教学完备性** + **实时推送链路** + **Agent Skills 生态布局**。

如答辩需要"市面上还有什么"，可以正面引用鱼皮项目作为同类对比，明确指出舆镜的三个领先点（可解释 / 沉淀 / 领域适配）和两个待补点（实时推送 / Agent Skills），体现自己的技术视野与诚实度。
