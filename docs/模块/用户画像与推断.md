# 模块 · 用户画像与推断

> 最后更新 2026-05-18 · 主入口 [app/services/profile_inference.py](../../app/services/profile_inference.py) · API [app/api/routes.py](../../app/api/routes.py)

## 1. 角色

把用户的**隐式行为**（浏览历史）转成可参与推荐打分的「**偏好源 + 兴趣标签 + 方面权重**」，并允许用户**编辑 / 删除 / 重置**。

## 2. 数据模型

`UserProfile` 表关键字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `user_id` | str | 单用户场景固定 `"default"` |
| `view_history` | JSON | 最近 50 条浏览（`[{article_id, viewed_at, action}]`）|
| `source_weights` | JSON | 推断的源偏好 `{source_id: weight}` |
| `tag_weights` | JSON | 推断的兴趣标签 `{tag: weight}` |
| `aspect_weights` | JSON | 关心的方面 `{aspect: weight}` |
| `inferred_tags` | JSON | 最终展示的 tag 列表（含 manual + 推断 - blacklist）|
| `inferred_tags_blacklist` | JSON | 用户删过的 tag（不再自动推荐）|
| `manual_tags` | JSON | 用户手动添加的 tag（最多 50，置顶）|
| `inferred_at` | datetime | 上次推断时间（用于 TTL）|
| `inferred_meta` | JSON | 推断元数据（候选数量等）|

## 3. 行为采集

前端每次进入事件 / 文章详情时调：

```
POST /api/profile/track
Body: { article_id: int, action: "view" }
```

后端：
1. 把记录 push 到 `view_history` 头部
2. FIFO 保留最近 50 条
3. 标记 `needs_inference=True`

## 4. 推断流程

文件 [profile_inference.py](../../app/services/profile_inference.py)。**异步触发**：用户访问 `/api/profile` 或 `/api/recommendations` 时若 `inferred_at` 距今 > `TTL_SECONDS = 1800`，后台 task 跑推断。

```
1. 取 view_history TopK = HISTORY_LOOKBACK = 50
2. 对每篇文章：
   - 累计 source → source_weights[source_id] += 1
   - jieba TextRank 提取 Top12 关键词 → tag_weights[tag] += 1
   - 取 article.aspects → aspect_weights[aspect] += 1（若有）
3. 取 view_history 中所有 article 的 BGE 向量平均 → user_vector
4. FAISS 召回近 NEIGHBOR_LOOKBACK_DAYS = 7 天的相似事件 TopK = NEIGHBOR_TOPK = 80
   - 过滤 cos < NEIGHBOR_MIN_COS = 0.55
   - 过滤用户已看过的
5. 对邻近事件做关键词聚合 → 补充 tag_weights
6. 计算 inferred_tags：
   - manual_tags 永远在前
   - + (tag_weights TopN 排序，过滤 blacklist)
   - 总长度 ≤ 50
7. 写回 UserProfile + inferred_at = now
```

## 5. 用户可干预接口

| 操作 | API | 字段变动 |
|------|-----|--------|
| 查询画像 | `GET /api/profile` | - |
| 记录行为 | `POST /api/profile/track` | `view_history` += |
| 删除自动 tag | `DELETE /api/profile/tag?tag=xxx` | `inferred_tags` -= , `blacklist` += |
| 添加手动 tag | `POST /api/profile/tag` body `{tag}` | `manual_tags` 首位插入，解除 blacklist |
| 删除偏好源 | `DELETE /api/profile/source/{id}` | `source_weights` -= |
| **重置整体画像** | `POST /api/profile/reset` | 清空 view_history / source_weights / tag_weights / aspect_weights / inferred_tags / blacklist / manual_tags / inferred_at / inferred_meta |

> **重置不影响订阅和屏蔽词**——这两个是用户显式数据，不是推断结果。

## 6. 与推荐的接入

```python
# recommend_service.py
def score(event, user_profile):
    score = 0
    # profile_source 项
    for src_id, w in user_profile.source_weights.items():
        if event.has_source(src_id):
            score += w * 3.0
    # profile_tag 项
    for tag in user_profile.inferred_tags:
        if tag in event.title or tag in event.summary:
            score += user_profile.tag_weights.get(tag, 1) * 3.0
    # ... 其他项
    return score
```

## 9. 已知限制

1. **单用户场景**：`user_id` 写死 `"default"`，多用户需登录系统
2. **关键词推断粗**：jieba TextRank 对短摘要效果有限
3. **画像可解释性弱**：用户看到 tag 不知道来自哪些文章（未来加「溯源」按钮）
4. **冷启 0 行为**：返回空画像，全靠订阅 + 热度
