# 情感分析模型对比文档

## 1 任务背景

舆情预警系统需要对抓取到的新闻与社交媒体文本进行**细粒度情感分类**，以驱动情绪分布可视化和事件情感趋势分析。我们定义了 **8 类情感标签**：

| ID | 标签 | 简体映射 | 说明 |
|:--:|:-----|:---------|:-----|
| 0 | 平淡語氣 | 中性 | 陈述事实，无明显情感倾向 |
| 1 | 關切語調 | 关注 | 关心、担忧、提醒他人 |
| 2 | 開心語調 | 喜悦 | 高兴、庆祝、积极正面 |
| 3 | 憤怒語調 | 愤怒 | 生气、不满、抗议 |
| 4 | 悲傷語調 | 悲伤 | 难过、失落、哀伤 |
| 5 | 疑問語調 | 质疑 | 提问、困惑、不确定 |
| 6 | 驚奇語調 | 惊讶 | 意外、震惊、出乎意料 |
| 7 | 厭惡語調 | 厌恶 | 反感、排斥、嫌弃 |

为选出最适合本系统的情感分类模型，我们在 **832 条人工标注的繁体中文对话样本** 上进行了对比评测。

---

## 2 对比模型

### 2.1 原始模型：xlm-roberta-large-xnli

| 属性 | 值 |
|:-----|:---|
| 基座架构 | XLM-RoBERTa-large (550M 参数) |
| 预训练任务 | 多语言掩码语言模型 (MLM) |
| 微调数据集 | XNLI (跨语言自然语言推理) |
| 分类方式 | **零样本分类 (Zero-Shot)** |
| 情感标签训练 | **无** — 通过 NLI 假设匹配间接推断 |

**工作原理**：该模型本质上是一个自然语言推理 (NLI) 模型，判断输入文本与候选假设之间是"蕴含 / 矛盾 / 中立"关系。做情感分类时，将每个情感标签构造为假设（如"这段话表达了愤怒"），选择蕴含概率最高的标签作为预测结果。

**核心局限**：
- 模型并未在任何情感标注数据上训练，对情感语义的理解仅来自 NLI 的隐式迁移。
- NLI 模型的训练偏向使其在面对含有疑问句式、反问句式的文本时，倾向输出"疑问"相关假设的高蕴含分数，导致**大量非疑问类情感被误判为"疑問語調"**。

### 2.2 改进模型：Johnson8187/Chinese-Emotion

| 属性 | 值 |
|:-----|:---|
| 基座架构 | XLM-RoBERTa (与原始模型同系列) |
| 微调数据集 | Chinese\_Multi-Emotion\_Dialogue\_Dataset (4,000 条繁体中文情感对话) |
| 分类方式 | **有监督多分类 (Supervised)** |
| 输出层 | 8 类 Softmax |
| 许可协议 | MIT |

**工作原理**：在 XLM-RoBERTa 基座之上，使用 `AutoModelForSequenceClassification` 添加了一个 8 分类线性头，在 4,000 条**人工标注的繁体中文多轮对话**上进行有监督微调。模型直接学习"文本 → 情感标签"的映射关系，不依赖间接的 NLI 推理。

**关键优势**：
- **专项训练**：在与目标任务完全一致的情感标注数据上微调，模型直接学会了中文情感表达的细微差别。
- **繁体中文原生**：训练数据为繁体中文对话，与舆情系统处理的港澳台及海外中文内容高度契合。
- **同系列基座**：与原始模型使用相同的 XLM-RoBERTa 预训练权重，确保了公平对比——性能提升完全来自**有监督情感微调**，而非更大的模型容量。

## 3 评测数据集

- **来源**：Johnson8187/Chinese\_Multi-Emotion\_Dialogue\_Dataset 中随机采样
- **规模**：832 条繁体中文短文本
- **类别分布**：

| 类别 | 样本数 | 占比 |
|:-----|:------:|:----:|
| 平淡語氣 | 141 | 16.9% |
| 開心語調 | 119 | 14.3% |
| 關切語調 | 112 | 13.5% |
| 憤怒語調 | 105 | 12.6% |
| 驚奇語調 | 100 | 12.0% |
| 悲傷語調 | 97 | 11.7% |
| 厭惡語調 | 81 | 9.7% |
| 疑問語調 | 77 | 9.3% |

类别分布较为均衡，最大类（平淡語氣）与最小类（疑問語調）的比例约为 1.83:1。

---

## 4 总体对比结果

| 指标 | 原始模型 (xlm-roberta-large-xnli) | 改进模型 (Chinese-Emotion) | 提升 |
|:-----|:--:|:--:|:--:|
| **正确数 / 总数** | 342 / 832 | 781 / 832 | +439 |
| **准确率 (Accuracy)** | 41.1% | **93.9%** | **+52.8pp** |
| **平均置信度** | 0.559 | **0.938** | +0.379 |
| **错误数** | 490 | 51 | -89.6% |

改进模型在准确率上提升了 **52.8 个百分点**，错误数减少了 **89.6%**，平均置信度从 0.559 提升到 0.938，说明模型不仅预测更准，而且对自身预测的确信程度也显著更高。

## 5 分类别对比

| 类别 | 样本 | 原始模型准确率 | 改进模型准确率 | 提升 | 原始置信度 | 改进置信度 |
|:-----|:----:|:---------:|:---------:|:----:|:------:|:------:|
| 平淡語氣 | 141 | 24.8% | **89.4%** | +64.6pp | 0.543 | 0.909 |
| 關切語調 | 112 | 18.8% | **95.5%** | +76.7pp | 0.608 | 0.953 |
| 開心語調 | 119 | 67.2% | **98.3%** | +31.1pp | 0.624 | 0.962 |
| 憤怒語調 | 105 | 13.3% | **96.2%** | +82.9pp | 0.474 | 0.926 |
| 悲傷語調 | 97 | 44.3% | **90.7%** | +46.4pp | 0.524 | 0.948 |
| 疑問語調 | 77 | **98.7%** | 93.5% | -5.2pp | 0.721 | 0.930 |
| 驚奇語調 | 100 | 56.0% | **95.0%** | +39.0pp | 0.564 | 0.945 |
| 厭惡語調 | 81 | 21.0% | **92.6%** | +71.6pp | 0.420 | 0.931 |

### 关键发现

1. **改进模型在 7 个类别上大幅领先**，其中"憤怒語調"提升最大（+82.9pp），"關切語調"次之（+76.7pp）。
2. **唯一例外是"疑問語調"**：原始模型 98.7% vs 改进模型 93.5%。这并非因为原始模型真正"擅长"识别疑问——而是因为它**过度预测疑问类**（见下文误分类分析），恰好在疑问类样本上命中率高。
3. **改进模型的置信度在所有 8 个类别上均超过 0.9**，说明分类决策稳定、不模糊。

## 6 误分类分析

### 6.1 原始模型的误分类模式

原始模型共产生 **490 次错误**，其中绝大多数被误判为"疑問語調"：

| 真实类别 | 主要误判方向 |
|:---------|:------------|
| 平淡語氣 | 疑問語調(56)、關切語調(30)、開心語調(10) |
| 關切語調 | **疑問語調(80)**、悲傷語調(4)、開心語調(3) |
| 憤怒語調 | **疑問語調(71)**、驚奇語調(10)、關切語調(5) |
| 厭惡語調 | **疑問語調(44)**、關切語調(7)、驚奇語調(6) |
| 悲傷語調 | 疑問語調(33)、關切語調(12)、驚奇語調(6) |
| 驚奇語調 | **疑問語調(41)**、關切語調(2)、平淡語氣(1) |
| 開心語調 | 驚奇語調(18)、疑問語調(14)、關切語調(6) |

**结论**：原始模型存在严重的**"疑问偏置"** (Questioning Bias)。490 次错误中，**339 次（69.2%）是误判为"疑問語調"**。这是因为 NLI 模型在面对含有反问、感叹、疑问词的中文句子时（如"怎麼會…"、"為什麼…"、"到底…"），倾向于认为"疑问"假设成立。而中文的愤怒、关切、惊讶等情感表达中大量使用反问和疑问句式，导致系统性误判。

### 6.2 改进模型的误分类模式

改进模型仅有 **51 次错误**，分布更加分散，无明显系统性偏差：

| 真实类别 | 误判方向 |
|:---------|:---------|
| 平淡語氣 | 關切語調(7)、開心語調(4)、厭惡語調(2) |
| 悲傷語調 | 疑問語調(4)、關切語調(4)、平淡語氣(1) |
| 厭惡語調 | 憤怒語調(6) |
| 疑問語調 | 關切語調(3)、驚奇語調(1)、平淡語氣(1) |
| 驚奇語調 | 開心語調(3)、關切語調(1)、平淡語氣(1) |
| 關切語調 | 平淡語氣(2)、悲傷語調(1)、驚奇語調(1) |
| 開心語調 | 平淡語氣(2) |
| 憤怒語調 | 開心語調(2)、驚奇語調(1)、厭惡語調(1) |

**结论**：改进模型的错误主要发生在**语义邻近的类别之间**（如"厌恶↔愤怒"、"悲伤↔关切"、"惊讶↔开心"），这些是人类标注者也容易混淆的边界案例，属于合理的分类模糊地带。

## 7 系统集成方案

### 7.1 双引擎架构

系统采用 **BERT 精标 + 规则兜底** 的双引擎架构：

```
文本输入
  │
  ├── BERT 引擎就绪？──是──→ Chinese-Emotion 模型推理 (Softmax 8分类)
  │                              │
  │                              ↓
  │                        返回 8 类概率分布
  │
  └── 否（首次加载/加载失败）──→ 规则引擎兜底
                                   │
                                   ↓
                             关键词匹配 + 归一化
```

- **BERT 引擎**：后台守护线程异步加载模型，加载完成前不阻塞主线程。支持单条推理 (`analyze`) 和批量推理 (`analyze_batch`)，批量模式下将文本按 batch_size=8 分批送入模型，减少 forward pass 次数。
- **规则引擎**：当模型未就绪或推理异常时自动降级，使用预定义的情感关键词词典进行匹配，保证系统在任何情况下都能返回情感分布。

### 7.2 输出格式

模型输出为 8 类概率分布，按概率降序排列：

```json
[
  {"label": "愤怒", "value": 0.964},
  {"label": "厌恶", "value": 0.021},
  {"label": "悲伤", "value": 0.008},
  ...
]
```

前端情绪分布图直接消费此概率数组，渲染为雷达图或柱状图。

## 8 结论

| 维度 | 原始模型 | 改进模型 |
|:-----|:------:|:------:|
| 总体准确率 | 41.1% | **93.9%** |
| 平均置信度 | 0.559 | **0.938** |
| 分类偏置 | 严重（69% 错误→疑问） | 无系统偏置 |
| 最弱类别 | 憤怒 13.3% | 平淡 89.4% |
| 推理方式 | 零样本 NLI | 有监督分类 |

**改进模型 Chinese-Emotion 在准确率、置信度、类别均衡性三个维度上全面优于原始模型**，其优势来源于：

1. **任务对齐**：直接在情感标注数据上微调，而非借助 NLI 间接推断。
2. **语言适配**：训练数据为繁体中文对话，与目标场景高度匹配。
3. **消除偏置**：有监督学习消除了 NLI 模型固有的"疑问偏置"，使 8 个类别的识别能力趋于均衡。

因此，舆情预警系统最终采用 **Johnson8187/Chinese-Emotion** 作为情感分析核心模型。
