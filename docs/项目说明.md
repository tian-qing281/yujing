> 最后更新 2026-05-18 · 项目概览 / 目录结构 / 快速上手

## 1. 项目简介

**舆镜（YuJing）** 是一个面向中文互联网舆情场景的一站式监控系统。系统从 **8 个主流平台**（微博、百度、头条、B 站、知乎、澎湃、华尔街见闻、财联社）实时采集热搜，对内容做：

1. **跨平台事件聚类**：把同一新闻的不同表述合并为一个事件实体
2. **细粒度情感分析**：8 分类 BERT + LLM 方面级抽取
3. **个性化推荐**：基于订阅 + 隐式画像的融合打分
4. **自然语言 Agent 问答**：11 个工具支持复杂查询 + 早报生成
5. **多维可视化**：事件时间线、平台对比、雷达图、Word/PPT 报告导出

技术栈：Python 3.10 / FastAPI / SQLite / Vue 3 / Vite / BGE / FAISS / MeiliSearch / DeepSeek。

## 4. 快速上手（开发）

详见 [部署文档.md](部署文档.md)。最短路径：

```powershell
# 后端
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env  # 填 DEEPSEEK_API_KEY
python -m uvicorn app.main:app --reload --port 8000

# 前端
cd yujing-ui
npm install
npm run dev   # http://localhost:5173
```

## 5. 核心数据流

```
[8 源爬虫] → Article 入库 → BERT 即时打标
   │
   └→ BGE 向量化 → 增量聚类挂到 Event
                    ↓
            APScheduler 每 30min
                    ↓
              Centroid 校准（2h）
   ↓
用户访问：
  /api/events       → 事件列表（带情感分布）
  /api/recommendations → 融合打分
  /api/ai/chat      → Agent 工具调用
```

## 7. 数据规模（参考）

连续运行一周（单机）：
- Article ≈ 50,000
- Event ≈ 6,000
- Topic ≈ 1,500
- 数据库文件 ≈ 500MB
- 单条 SSE 对话端到端 ≈ 5s
